Floating-collage hero source images.

Drop the three materials here with these exact filenames:

  fan.png        — Cantonese export fan painting
  ink-tree.png   — blue ink blossom tree
  pink-city.png  — pink watercolour city

PNG with a transparent (or pale/white) background works best — the hero
uses mix-blend-mode: multiply so pale backgrounds melt into the paper.

To change positions/sizes/rotation, edit FRAGMENTS in
src/components/FloatingCollageHero.jsx.
